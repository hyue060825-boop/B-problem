# Q4：含定向源的搜索、定位与清除

定向源只在未知的闭发射半平面内可见，因此一次无信号不能像全向源那样直接排除整个圆盘。当前方法以三角网格保证发现，再沿用有界误差定位与清除控制。

## 三角网格与发现证明

取边长 `s=995 m<1000 m` 的等边三角网格，收集所有与半径 1800 m 闭目标圆相交的三角形及其顶点。当前实现得到 **42 个三角形、31 个站点**，并保留圆内网格顶点的六个非重合邻点。

设源位置 x 位于三角形 `conv(v1,v2,v3)`，则 `x=Σλ_i v_i`、`λ_i≥0`、`Σλ_i=1`。对任意单位发射方向 u，若所有顶点均在严格背面，即 `u·(v_i-x)<0`，加权求和将得到 `0<0`，矛盾。因此至少有一个顶点位于闭发射半平面，且其距 x 不超过三角形直径 s，满足保证接收距离。

源与网格顶点重合时，不能依赖零向量的方向定义；六个非重合邻点距源 995 m，方向间隔 60°，至少一个与发射方向夹角不超过 30°，补足此情况。

代码为 [triangular_grid](../../src/solution/coverage/certificates.py)，坐标及核验结果在 [q4_grid.json](../tables/q4_grid.json)，图见 [F005](../figures/F005-q4-directional-coverage.pdf)。右侧是数学示意，不是实际运行轨迹。旧报告的 46 个三角形/41 个站点属于早期版本。

## 搜索、定位与退出

五类宏动作与 Q3 共用，详见[Q3 实际算法](../q3/README.md)。定向源的正观测仍形成测向和距离约束；单次无信号不排除整圆。当前新增的认证规则是：某频道在完整认证网格的全部站点均无信号，才允许将其标为不存在。认证还核对站点位置，不能用任意位置的无信号凑满站点数量。

旧控制器曾在已清除所有源后重复扫描、不能退出。`3ddb2d9` 已接收不存在认证和去除重复重扫等修复；清除覆盖一次快照顺序执行，避免失败后反复从同一点开始。只有所有频道均解决时退出；发现满 16 个源后，可利用题面源数上界认证其他频道不存在。

规则回归包含不同源数、空间布局和误差场的交叉场景。修复动机、代码与日志见[Q4 修复报告](../../results/training/import-3ddb2d9/reports/Q4修复与四卡同步复验.MD)及 [test_q4_repair.py](../../tests/solution/test_q4_repair.py)。覆盖发现证明不等于已证明全部清除操作都在每局预算内完成。

## 实验过程与当前结果

先使用修复后控制器完成 BC/DAgger/PPO，同步四卡训练；再从该阶段 best 进行预算微调，共 3800 轮，验证集选中第 3500 轮。配置分别见 [repaired_20260912.json](../../experiments/q4/repaired_20260912.json)和 [budget_20260912.json](../../experiments/q4/budget_20260912.json)，共同训练说明见[训练与评估](../shared/训练与评估.md)。

最新在种子 `320000000–320002999` 的 3000 个研究场景上，与预算训练前的模型配对，二者使用相同场景和当前控制器。

| 指标 | 训练前对照 | 预算训练 best |
| --- | ---: | ---: |
| 完成场景数 | 3000/3000 | 3000/3000 |
| 平均每局虚拟总耗时 T / s | 10187.40 | 9879.05 |
| 逐局 T/C 的均值 / (s/源) | 806.51 | 784.35 |
| sum(T)/sum(C) / (s/源) | 782.62 | 758.93 |

平均配对总耗时差为 -308.35 s，近似 95% 区间 `[-343.25,-273.45]` s；1888 局更快、1112 局更慢。总时间均值改善约 3.03%，逐局 T/C 均值改善约 2.75%，不能表述为每局都更快。best 的样本最大总耗时约 21618.47 s，高于对照的 20061.08 s，因此平均收益与尾部表现分别解释。

原始记录见[最新配对批次](../../results/training/import-3ddb2d9/runs/q34_3000_test_20260912/)，表格和图件见 [q34_summary.csv](../tables/q34_summary.csv)、[q34_paired.csv](../tables/q34_paired.csv)、[F006](../figures/F006-q34-per-source-ecdf.pdf)、[F007](../figures/F007-q34-paired-by-count.pdf)和 [F008](../figures/F008-q34-validation-progress.pdf)。

## 文献启发补充 · LIT-Q2-01｜待验证方案

[L2](../../docs/references/README.md)提供网格定位质量分析的背景，本题网格则首先保证定向源被发现。两类保证应分别论证：至少一个可见站点不代表交会定位已足够精确。

Q2保证接收集合只适用于全向源；定向场景增加形状候选时，还需处理未知发射半平面的可见性。无法保证有信号时，必须明确无信号分支和恢复路径，不能按全向规则排除整圆。本轮仅补方案，现有控制器、权重、退出修复和上述3000场景结果保持原版本。

本批方法与证据见[独立交付](../shared/文献启发与Q2改进说明.md)，进一步推导已补入[总体方案](../../docs/model/总体方案.md)。
