# 共同记号与模型接口

题意的完整约束见[题目阅读](../../docs/notes/题目阅读.md)及[原始附件](../../problem/README.md)。本文只统一四问交付中的记号和解释。

| 记号 | 含义与单位 |
| --- | --- |
| `x`、`s`、`q` | 源位置、已有检测点、候选动作位置；东向 x、北向 y，单位 m |
| `theta`、`epsilon` | 测得示向度与误差界；从 +x 轴逆时针，以度为接口单位 |
| `K`、`H` | 当前物理可行集及其凸包；未观测隐藏真值不属于策略输入 |
| `D`、`R_MEC` | 可行域直径、最小包围圆半径，单位 m |
| `N`、`C` | 场景真实源数、成功清除数；正式运行时 N 未知 |
| `T`、`t=T/C` | 本局虚拟总耗时、每个已清除源的均摊耗时；C=0 时不得直接相除 |

题面测向误差界为 ±1°，同一位置的误差固定。当前几何实现用 `epsilon_impl=1.01°` 包含返回角度量化等数值保护；它不意味着题面误差界改变。理论距离阈值为 5、20、1000、1500、1800 m，程序根据包含/排除关系使用内外接多边形及少量保护量。

对普通正观测，位置约束包含前向角域、目标圆和已知距离上界；`near` 给出 5 m 距离信息。全向源的无信号可用于排除保守接收圆；定向源单次无信号不能如此处理。失败清除排除对应 20 m 邻域，成功后将频道标为已清除。

当前虚拟耗时可按动作账目写为

$$
T=L/5+n_{\mathrm{switch}}+5n_{\mathrm{measure}}+3n_{\mathrm{clear}}+2C.
$$

其中 `n_clear` 包括成功与失败尝试；成功清除合计 5 s，失败 3 s。`clear` 不改变测向频道。虚拟耗时、模型推理时间和整段程序墙钟耗时须分别记录。

几何证书为在线策略提供两类依据：若可行集中每个可能位置距清除点均不超过清除阈值，可以保证清除；若频道在完整认证覆盖中始终无信号，可以证明不存在。当前控制器只在所有频道为 `CLEARED` 或 `ABSENT_CERTIFIED` 时退出。有限场景全部完成不替代所有合法场景的时限证明。
