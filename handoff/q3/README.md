# Q3：全向干扰源搜索、定位与清除

从源数未知的全向场景出发，用确定的覆盖结构保证发现与不存在认证，再由可行域和清除证书约束在线动作，用启发式或学习调度减少虚拟时间。

## 覆盖模型

在原点设置中心站，半径 `a=1135 m` 的正六边形顶点设置 6 个外圈站。按保守接收半径 `r_safe=999.98 m`，中心圆覆盖内区。外侧任一点与最近六边形顶点的夹角不超过 30°，距离上界由

$$
\max_{r\in\{r_{\rm safe},1800\}}
\sqrt{r^2+a^2-2ra\cos(\pi/6)}=994.809\ldots<r_{\rm safe}
$$

给出；径向平方距离为凸函数，检查环带两端即可。因此七个接收圆覆盖目标圆。对某频道完整扫描这组站点仍无信号时，可认证不存在；已发现频道转入定位与清除。

构造与核验代码见 [coverage/certificates.py](../../src/solution/coverage/certificates.py)。覆盖图 [F004](../figures/F004-q3-coverage.pdf)不表示实际访问次序或最短路线；不同 a 的几何核验数值见 [q3_coverage_parameters.csv](../tables/q3_coverage_parameters.csv)，这只是覆盖参数检查，不是策略耗时灵敏度实验。

## 实际在线算法

[controller.py](../../src/solution/control/controller.py) 与 Q4 共用以下五类宏动作，流程见 [F001](../figures/F001-controller-workflow.pdf)。

| 宏动作 | 当前行为 |
| --- | --- |
| COVER | 从最近的至多 3 个未访问站点生成候选，串行检测仍需搜索或补测的频道 |
| LOCALIZE | 在可行域最小包围圆圆心沿最后示向度的垂向两侧生成位置；偏移量由半径限制在 30–350 m，每源专门补测至多 3 次 |
| CLEAR | 到已有清除证书的圆心执行清除；near 时立即原地清除 |
| PROBE_CLEAR | 用多个清除圆覆盖可行域，按最近剩余点执行，成功立即停止 |
| EXIT | 所有频道已清除或已认证不存在时退出 |

规则教师根据动作估计成本和固定偏置排序，学习模型对同一合法候选集排序。扫描时尽量先用当前频道，相邻站点标签使用相反频道排序。完整流程以每次公开响应更新状态，不读取真实源数。

当前补测不是 Q2 完整选点器；当前保证清除点取圆心，也未实现最近插入、2-opt 或 Held–Karp 路线优化。这些可作为进一步设计，不能用于解释现有耗时结果。

## 训练、评估及结果

训练采用 Q3 搜索教师辅助的 SFT、DAgger、PPO；细节、特征、数据分割和同步 DDP 见[训练与评估](../shared/训练与评估.md)。相关配置为 [joint_20260912.json](../../experiments/q3/joint_20260912.json)。

最新两份固定权重在种子 `310000000–310002999` 的 3000 个研究场景配对评估，每局 10–16 个源、最多 400 个宏动作。对照是冻结旧训练模型。

| 指标 | 对照 | PPO 候选 |
| --- | ---: | ---: |
| 完成场景数 | 3000/3000 | 3000/3000 |
| 平均每局虚拟总耗时 T / s | 3336.74 | 3322.42 |
| 逐局 T/C 的均值 / (s/源) | 261.69 | 260.63 |
| sum(T)/sum(C) / (s/源) | 256.44 | 255.33 |

平均配对总耗时差为 -14.32 s，近似 95% 区间 `[-19.25,-9.39]` s；候选在 1651 局更快、427 局持平、922 局更慢。总时间均值改善约 0.43%，逐局 T/C 均值改善约 0.40%。原稳健验证规则仍推荐 baseline，故保留“候选”称谓。

数据见[最新原始批次](../../results/training/import-3ddb2d9/runs/q34_3000_test_20260912/)，整理表为 [q34_summary.csv](../tables/q34_summary.csv)、[q34_paired.csv](../tables/q34_paired.csv)。可取用图 [F006：耗时分布](../figures/F006-q34-per-source-ecdf.pdf)、[F007：按源数分组](../figures/F007-q34-paired-by-count.pdf)、[F008：训练验证](../figures/F008-q34-validation-progress.pdf)。
