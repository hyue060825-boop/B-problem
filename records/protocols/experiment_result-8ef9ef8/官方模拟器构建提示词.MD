你是一名负责数值仿真、HTTP协议、强化学习环境和可靠性验证的开发工程师。请基于提供的官方原文件，搭建2026年数学建模竞赛B题的本地训练与测试环境。目标是实现可审计、可重放、可高速运行的公开规则内核，并在证据允许的范围内验证与官方行为一致；不能把未知规则自行补全后称为“官方同款”。

### 4 一致性模式必须明确

至少划分三种用途，严禁混合标识：

1. `strict_official`：完整复刻目标。依赖的未决项没有证据时，在启动该功能前明确失败，显示缺口ID；无默认场景分布、默认噪声场或默认微秒舍入。可以完成代码骨架与已确认子模块，但不能报告完整环境已验收。
2. `fixture_conformance`：测试夹具模式。由测试明确提供源状态、固定误差表或可验证函数、时钟、量化策略；用于验证已知物理和协议。夹具的自定参数必须醒目标注为测试输入，不能宣称为官方内部实现。
3. `compatible_research`：只有用户另行明确接受“公开规则相容、隐藏分布未确认”的有限目标后才启用。每个假设均有配置、标签和清单，不允许静默退回此模式。该模式的测试结论不能进入“完整官方一致”栏目。

在目前用户要求必须一致的情况下，默认执行第1和第2类可完成工作。阻断项不是让你完全不写代码的理由，但它阻止你发布一个冒称一致的随机训练环境。

### 5 官方物理规则

源真值结构应包含：频道1—20、二维位置、接收半径、类型、定向朝向（全向为空）、清除标记。常规官方模式N∈[10,16]，源在半径1800米目标圆内，频道互不重复。问题3全为全向；问题4既有全向又有定向，不知道两类数量。额外课程及全定向压力案例放独立配置，不能混入常规成绩。

全部源位置与物理参数在一局中保持不变，除清除状态外。不同源信号互不干扰。

机器狗可以出目标圆。坐标有限且每个分量绝对值≤2000000米。不要加“必须留在圆内”、障碍物、碰撞、加速度、转向时间、返回原点、移动中检测等规则。

对于源g和检测点p，令d=||g−p||。若目标不存在或已清除，返回no_signal。否则：

- d>R：no_signal。
- 若为定向且检测点不在从源出发的±90°闭半平面内：no_signal。
- 通过上述可接收判断后，d≤5：near，无svd_deg。
- 其余：direction，返回含固定地点误差且按官方量化规则归一化的角度。

一般非重合点的定向判据为`u(phi) dot (p-g) >= 0`。测向真实角为`atan2(g.y-p.y, g.x-p.x)`转换成度。两处向量相反，必须单独测试。q=g的定向特例按G06处理，不能用编程语言的atan2(0,0)默认值悄悄定规则。

同地点重复检测同一未清除源必须重复相同读数，不因动作ID、请求次数或采样顺序变化。固定误差在[−1°,1°]，但不能据此默认均匀分布，也不能默认不同地点独立。示向度保留两位小数，只有direction返回它。

清除只看指定频道未清除源的距离是否≤20米，与定向朝向、是否能收信号无关。成功返回`success`并置清除标记；否则返回`no_target_in_range`。清除不改变测向频道。不得返回真坐标、距离或半径。

### 6 状态与计时

会话生命周期至少包含：空闲、准备/倒计时、接口就绪但未enter、已进入、已结束。非测试、倒计时、结束后官方接口未开放，连接失败是正常行为，不应强制模拟为HTTP 200。

界面开始测试后准备数据，再倒计时5秒；倒计时结束开启25分钟窗口并开放接口。首次成功enter后位置(0,0)、测向频道1、虚拟时间0，并开始最多20分钟的程序运行计时。现实截止=min(窗口开启+1500秒, enter成功+1200秒)。enter返回实际剩余完整秒数，范围0—1200；精确取整细节如缺证据要记录。

虚拟时间计算：

```text
measure(p,c):
    move = distance(previous_position,p)/5
    switch = 1 if c != current_measure_channel else 0
    dt = move + switch + 5
    position = p
    current_measure_channel = c

clear(p,c):
    move = distance(previous_position,p)/5
    dt = move + (5 if clear_succeeds else 3)
    position = p
    current_measure_channel unchanged

enter / exit:
    dt = 0
```

拒绝的请求不改变位置、频道、清除状态或时钟。只有accepted=true的动作才提交状态；幂等重放虽返回原accepted=true，却不再执行任何动作或累计时间。

内部累计微秒，响应virtual_time_s为JSON number，最多6位小数，去无意义尾零；禁止先把每段距离取整到米或把累计时间取整到秒。G05未解决时使用显式夹具策略验证，strict完整模式不能偷偷选round/floor。

达到现实或虚拟限时结束测试，虚拟上限360000秒。截止前完整到达并登记的唯一动作允许完成，截止时或之后才完整到达的请求不执行。测试“从359999秒开始的合法动作可能完成后超过360000秒”的跨界情形，不能一律把动作硬截在上限；同时核查登记与现实截止的顺序。结束后不能通过exit查询原因。

提供可注入的测试时钟，不必为验证20分钟和25分钟在现实中等待。生产兼容层用单调时钟计间隔、现实时间戳生成响应；测试时钟不能通过机器狗接口被控制。

### 7 四个接口及响应

官方默认监听`127.0.0.1:2026`，可空闲改端口。兼容层默认本机回环。训练批量并行使用进程内接口或独立本地会话，绝不能向一个官方会话并发发送新动作。

公共请求字段：

```json
{
  "arena_id": "default",
  "robot_id": "<本地会话配置的队号>",
  "request_id": "<会话内唯一动作ID>"
}
```

enter和exit只接收公共字段；measure和clear再接收：

```json
{
  "position": {"x": 300, "y": 400},
  "channel": 1
}
```

本地测试会话的队号由管理配置注入，不等于实现或绕过官方身份认证。对官方运行必须使用当前登录参赛队号。

所有JSON业务响应公共字段：accepted布尔值、real_timestamp_ms数值、virtual_time_s数值。accepted=false业务响应仅这三个字段，virtual_time_s固定0；机器狗不能用它覆盖最近一次有效时钟。

| 成功接口 | 额外响应字段                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------ |
| enter    | max_virtual_duration_s=360000，max_real_duration_s=1200，remaining_real_duration_s∈[0,1200]整数 |
| measure  | measure_result∈{no_signal,near,direction}；仅direction有svd_deg                                 |
| clear    | clear_result∈{success,no_target_in_range}                                                       |
| exit     | exit_reason="user_exit"                                                                          |

不在机器狗响应中增加调试真值、N、剩余源数、奖励、种子、清除源坐标、源类型、source_id等。训练评价信息走独立评估通道，并确保actor不可读取。

### 8 请求校验和错误行为

逐条实现附件2 §5，不依赖框架默认行为恰好一致：

- 只接受POST；路径精确为4个端点，不接受尾斜线、查询串。
- Content-Type为application/json，只允许附带charset=utf-8参数；Content-Encoding缺省或identity，其余415。大小写等未说明的HTTP细节按标准和证据标记，不能夸大逐字一致。
- 无BOM UTF-8 JSON对象，禁止重复键，深度≤16，体积≤65536字节。
- channel为1—20的整数数值；JSON 1.0若恰为整数也接受；1.5拒绝。不要把布尔true作为Python整数1接受。
- 坐标为有限JSON数值且分量绝对值≤2000000；NaN、Infinity及越界400，不改变状态。
- arena_id必须为ASCII字符串default；robot_id逐字节匹配队号，UTF-8长度1—64字节；request_id长度1—128字节；二者不得包含控制字符或不可见格式字符。
- 未知字段不忽略，包括position下的未知字段。

状态码：

| 返回               | 意义                                         |
| ------------------ | -------------------------------------------- |
| 200 accepted=true  | 接受并执行或重放原响应                       |
| 200 accepted=false | 未知字段、身份/arena不匹配、当前业务状态拒绝 |
| 400                | JSON/重复键/缺字段/类型/标识符/数值范围错误  |
| 404                | 未知或不精确路径                             |
| 405                | 已知路径但非POST                             |
| 409                | 同ID不同动作，或并发不同动作                 |
| 413                | 请求体过大                                   |
| 415                | 不支持的Content-Type/Encoding                |
| 429                | 连接或无效流量保护、幂等容量限制             |
| 500                | 内部错误                                     |

能形成HTTP响应的错误要返回JSON，至少包含三个公共字段；连接被关闭时不保证有JSON。校验优先级未明确时只验证“单一错误”的确定行为，把复合错误列G07。

框架默认重复键覆盖、自动斜线跳转、422参数错误、宽松布尔转数字、允许NaN等都必须审查。未知字段不能直接让框架返回422代替官方200 accepted=false。

### 9 幂等与串行事务

每个新动作新request_id。网络超时或中断后，同一个动作使用原ID与原请求内容重试。相同ID相同内容返回第一次完整响应，保留原时间戳及virtual_time_s，不重新检测、不重新生成误差、不再次移动或清除。

相同ID改路径、坐标、频道等返回409且无副作用。结构错误400、未知字段或arena/robot不匹配不占ID，修正后允许复用。被接受的业务动作占ID。其他未明的拒绝/并发状态是否占ID要审计，不补写为官方事实。

服务器使用会话锁和事务式提交，保证不同动作不会交错改变状态。同ID正在执行时的合并/等待行为、超时后关闭接口时的缓存投递若原文未完整定义，按G07/G08记录；客户端只采用原请求完整复用，不依赖JSON不同字节表示被判同义。

exit适用相同幂等规则，同时官方测试结束会关闭接口。因此必须区分“业务缓存的幂等性”和“网络还能否送达缓存”，不能承诺exit后重连一定成功。

429阈值和幂等容量不能编造后声称官方相同。夹具可用测试阈值注入故障，常规合法串行动作不加人为速率上限。

### 11 训练接口的真值隔离

批量环境可以内部存隐藏源数组，但给策略的观测必须能完全由官方请求响应历史构造。不能以训练方便为由直接提供真实位置、剩余总数、类型、R或φ。

训练奖励可以由评价模块计算并用作学习信号，不能作为部署时不可得的actor输入。主策略与价值网络首版都使用观测信念；如果后续采用训练专用特权critic，必须单独说明并证明actor推断不依赖特权信息。

底层action为measure(position,channel)或clear(position,channel)，加会话enter/exit；动作步不等于现实5秒等待。宏动作由算法层展开，不能让一个HTTP指令同时扫20频道。环境可返回terminated/truncated等训练包装字段，但不可把这些额外字段混入官方兼容HTTP响应。

本地批量reset是训练管理操作，不增加官方第五个接口。测试模式、隐藏场景、时间注入、种子设置通过隔离的管理接口或本地函数完成，不对策略进程开放。

### 12 随机性和重放

仅在允许的配置中生成随机场景。种子、源真值和误差场状态记录在评价侧，足以重放。重复同一场景与动作序列必须得到相同业务观测和虚拟时钟；现实时间戳只有使用注入时钟时才要求逐字相同。

固定误差场是“场景与位置等已定义变量的固定函数”。禁止在每次measure调用里直接新抽一个独立误差。不能只按首次访问顺序缓存随机值然后让查询顺序决定整个空间场，除非官方明确如此；研究模式需要可复现且明确标注的场定义。

若用户之后同意研究模式，至少测试数种固定场结构及场景分布；每一种说明假设，不把均匀噪声、独立半径、独立源位置称为官方设定。精确半径1000/1500、定向角边界等在确定性夹具中覆盖，不靠随机抽样碰到。

### 13 必须实现的验收测试

#### 13.1 官方计时示例

构造满足“频道3清除失败”的夹具，严格重放附件2 §10：

| 步骤 | 动作      | 参数             | 期望累计虚拟秒 |
| ---- | --------- | ---------------- | -------------: |
| 1    | enter     | 初始             |              0 |
| 2    | measure   | (300,400)，频道1 |            105 |
| 3    | measure   | (300,400)，频道2 |            111 |
| 4    | clear失败 | (300,0)，频道3   |            194 |
| 5    | measure   | (300,0)，频道2   |            199 |
| 6    | exit      | 原地             |            199 |

这项必须完全一致，可直接发现clear错误切换频道或移动重复计费。

#### 13.2 可人工算清的物理夹具

使用源(0,0)、R=1000、频道7；定向时朝向0°。测试夹具可只含一个源，但须显式关闭“正式场景10—16源”校验或补充无关合法源，不能修改生产场景规则。

| 测点/动作                    | 预期                                                       |
| ---------------------------- | ---------------------------------------------------------- |
| 全向measure(3,4)             | near                                                       |
| 全向measure(6,0)             | direction，真实角180°；输出需按注入固定误差及量化策略计算 |
| 全向measure(1000,0)          | direction，距离边界包含                                    |
| 全向measure(1000+δ,0)，δ>0 | no_signal                                                  |
| 定向measure(−3,0)           | no_signal，即使距离小于5米                                 |
| 定向measure(0,6)             | direction，±90°边界包含                                  |
| 定向clear(−20,0)            | success，与背向无关                                        |
| 任意源clear(20+δ,0)         | no_target_in_range                                         |
| 同一源再次clear              | no_target_in_range                                         |
| 已清除后measure              | no_signal                                                  |

每项用独立重置夹具，或明确前序清除状态。加测坐标正好与源重合，但该项的定向预期在G06解决前保持未决，不能把未测记通过。

#### 13.3 误差与角度

测试误差端点−1、0、+1，0°附近与359.995°等量化临界，同点不同request_id重复测量、换频道再切回来、离开再回到同点。校验固定误差和字段存在性。跨频道相关性及无限小位移行为只在有证据的profile中断言；研究profile做标注测试。

#### 13.4 幂等、校验与状态

重复ID同动作只计费一次；响应丢失后复用ID不会多清除一次；同ID改频道/路径409；400不改状态且不占ID；未知字段200 false且不占ID；enter前measure拒绝；新的ID重复enter拒绝；并发不同动作409；非法请求后下一合法动作从上一次合法位置计移动。

检查请求边界体积、深度、UTF-8多字节长度、BOM、重复键、未知嵌套字段、路径尾斜线、查询串、非POST、Content-Type参数、编码、布尔值与1.0的区别、NaN/Infinity、频道范围、坐标边界及超过边界。

幂等重放返回首次响应，包括首次时间戳，不把新时间戳伪称“完整原响应”。未公开阈值相关429测试标记为注入故障测试。

#### 13.5 截止与计时

enter在窗口开启后1分钟、5分钟、10分钟等时刻进入；超时前完整登记动作允许完成；截止时/之后请求不执行；虚拟跨上限动作；手工中止；exit不移动也不增时；接口关闭后无JSON的客户端恢复；不能用accepted=false中的0覆盖累计时钟。

对带非整数距离的长轨迹检查微秒累计。G05没有官方预期时，必须报告未决，不能仅两个共用同一舍入函数的实现互相一致就宣布官方正确。

#### 13.6 等价性与信息泄漏

对相同显式场景、误差函数、动作序列、注入时钟，参考内核/HTTP路径/批量内核逐步比较状态、观测、清除结果和时钟。随机属性测试与人工边界夹具并用。

额外审计actor输入字段，检查无隐藏真值；同一可观测历史产生相同actor输入，不因评价侧不同真值而变化。检查动作掩码同样只能来自可观测事实及合法几何推理，不能靠隐藏源是否存在屏蔽动作。

### 14 与官方演练对照的正确方法

先确认所用模块是问题3或4的“演练测试”，而不是正式测试。演练不限次数，正式每问3次，中止照常占用正式次数。不要为探测规则浪费正式机会。

默认本任务只制作采集与比较工具，不自动登录或启动官方运行；需要实际演练时先检查当前授权和官方软件状态。客户端自行记录请求和响应，避免将业务输出之外的本地文件作为策略观测。

可对照的项目：相同位置重复检测是否固定、返回角精度、由已接受位置序列计算的耗时、clear不切频道、清除后响应、官方返回剩余时间、合法请求与拒绝行为。利用这些建立轨迹核对报告。

如果不能指定官方隐藏场景，也不能读取完整真值，不能把本地同一随机种子与官方案例编号对应后宣称逐动作一致；两者没有这种已知映射。分为：

- 有确定隐藏夹具时，逐字段比较。
- 无确定隐藏夹具时，只比较规则不变量、可验证关系和总体统计，并报告无法识别的参数。

官方只在演练结束显示源总数及两类数量，正式不显示这些真值；不能假定演练会导出全部坐标、半径和误差场。

### 15 性能工作必须晚于规则验收

参考内核先通过已确认测试，再实现批量版本。在八卡服务器上测CPU、内存、GPU拓扑和每卡可用显存，输出实际吞吐与配置，不预设达到某个每秒回合数。

先每卡64—256环境做基准，统计物理步、信念更新、几何计算、数据传输各自耗时，按瓶颈优化。可在一个进程内批量运行许多独立模拟局；这不改变官方一只机器狗、一局动作串行的语义。

若采用近似内核探索，必须与参考内核明确区分，不能用低精度误判出来的高分训练结果通过正式迁移验收。已知物理阈值不做域随机化；未知分布的随机化仅在获准研究模式中进行。

### 17 最终交付与验收报告格式

交付可运行源码、锁定依赖、参考与批量内核、4接口服务、客户端、夹具、重放器、测试、规则矩阵、缺口表、运行说明和性能实测。

`docs/conformance_report.md`必须分别写清：

1. 已确认并通过的公开物理规则。
2. 已确认并通过的常用协议与计时行为。
3. 与官方实测对照了哪些行为，样本多少。
4. 哪些仅在自定夹具或自定研究profile下通过。
5. 哪些仍被G01—G09等阻断。
6. 能否启动strict完整模式，能否开始满足当前用户要求的大规模训练。

报告每项状态为PASS、FAIL、BLOCKED或NOT_RUN。不要把BLOCKED算作PASS，不要用“整体测试全通过”掩盖没有覆盖的官方关键项。

只有有充分证据时才能声称“与官方一致”，并明确一致范围是公开物理、协议、隐藏分布还是逐次输出。如果仍只有这三份附件，预期的诚实结论是：已实现可确认模块和夹具；完整官方复刻仍被固定误差场及场景生成过程等阻断。

完成所有不依赖缺失信息的工作后，集中提出最少的必要补充请求，优先索要：官方随机案例生成说明、固定误差场与位置键定义、角度/时间量化实现、边界参考样例。说明它们为何影响结果，不要求用户反复确认已授权的普通开发步骤。

### 18 不得出现的错误

- 每次measure都新抽±1°独立噪声，再让模型原地平均。
- 将接收半径固定为1000、1250或1500米，并称为官方。
- 默认所有参数均匀且独立抽样，或把“随机”解释成均匀分布。
- 定向源背面5米内也一律near。
- 定向源背面20米内不能clear。
- clear改变测向频道或收取切换时间。
- 把移动限制在目标圆内，或强制返回原点。
- 给策略提供真值N、源坐标、R、类型、朝向或剩余源数。
- 将微秒累计时间取整到秒；拒绝响应清空有效时钟。
- 网络重试生成新ID；重复动作再次计费；不同动作并发。
- 用框架默认422、重定向或忽略未知字段代替官方协议。
- 训练批量接口偷偷增加官方服务没有的观测或动作。
- 本地日志冒充官方加密日志，或把自制随机案例当官方正式测试。
- 在缺口没解决时，用更长训练时间和更高GPU利用率掩盖模拟器失配。

请现在从规则审计开始，执行可完成的工程工作。每阶段用代码、夹具和明确证据汇报，不只写计划；不依赖猜测制造“完成”。
