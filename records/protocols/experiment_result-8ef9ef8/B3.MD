# 2026 数模国赛 B 题：SFT—DAgger—PPO 三层训练重点版

> 本文可直接发送给队友及其 AI。重点是第三问、第四问的策略训练。

## 1. 总体架构

```text
自建二维数值环境
→ 20频道粒子信念
→ 最多32个候选动作
→ 可观测规划专家（A*/TSP/信息增益）
→ SFT
→ DAgger
→ PPO
→ 确定性覆盖与退出安全层
→ 官方模拟器演练
```

A*不是训练层，而是专家的规划组件。若模型随机初始化，SFT相当于模仿预训练，DAgger是在线模仿修正，PPO是奖励微调。

## 2. 共同输入与可见性边界

模型输入：

```text
global_features     [B,5]
channel_features    [B,20,10]
candidate_features  [B,32,14]
masks               [B,32]
```

包含机器人位置、当前频道、虚拟时间、20个频道的存在概率/定位均值/协方差/检测次数/发现与清除状态，以及候选检测和清除动作。模型输出32个候选动作的logit及状态价值。

环境内部可以读取源数量、频道、真实坐标、接收半径、类型和定向角，用来生成反馈和终局奖励。主体专家、Actor和最终策略不能读取这些真值，只能看到：

```text
direction + svd_deg
near
no_signal
success
no_target_in_range
virtual_time_s
```

策略不直接回归任意坐标。解析模块先产生合法候选动作，模型只负责选择。

## 3. 第一层：SFT

### 作用

让随机策略先学会覆盖搜索、频道调度、第二视点、交会定位、清除和失败恢复，避免RL从随机动作开始探索稀疏的整局奖励。

### 数据生成

自建环境随机生成隐藏场景，运行只读取信念的专家：

```text
生成隐藏场景
→ 由当前信念生成候选动作
→ 专家给候选动作评分
→ 保存状态、专家分数和最优动作
→ 环境执行动作并返回官方式反馈
→ 更新信念
→ 重复直到满足退出条件
```

每步保存：

```text
global_features
channel_features
candidate_features
masks
expert_action
expert_scores
episode_id
```

真实目标坐标只能进入环境日志和独立评测，不能进入模型特征。

### 专家标签

专家对候选动作计算：

\[
Q(a)=\Delta T(a)+\lambda_1H_{after}(a)+\lambda_2T_{remain}(a)-\lambda_3P_{clear}(a).
\]

- \(\Delta T\)：移动、切换频道、检测或清除耗时；
- \(H_{after}\)：动作后的预期定位不确定性；
- \(T_{remain}\)：A*/TSP估计的剩余访问时间；
- \(P_{clear}\)：清除成功的后验概率。

已知真实坐标的TSP只用于理论下界和已定位目标的清除排序，不能直接给初始未知状态打标签。

### 损失与配置

\[
L_{SFT}=L_{CE}+0.2L_{KL}.
\]

CE学习专家最优动作，KL蒸馏专家对全部候选动作的软排序。

```text
场景数：先1000局冒烟，正式2万—5万局
batch size：512
学习率：3e-4
epochs：20—40
优化器：AdamW
梯度裁剪：1.0
```

训练、验证、测试按完整episode/scene seed切分。SFT验收使用完整轨迹的全部清除率、平均时间、P90/P95、测量次数和失败清除次数，单步分类准确率只用于诊断。

## 4. 第二层：DAgger

### 作用

SFT主要见过专家轨迹。学生一次错误可能进入训练集未覆盖的信念状态。DAgger专门收集学生自身轨迹上的纠正标签。

### 执行流程

```text
学生选择动作
→ 环境返回反馈
→ 更新到学生真正到达的信念状态
→ 专家在该状态重新评分
→ 保存“学生状态—专家动作”
→ 与历史数据聚合
→ 继续监督训练
```

混合策略为：

\[
\pi_i=\beta_i\pi_E+(1-\beta_i)\pi_\theta,
\qquad \beta_i=\max(0.05,0.7^i).
\]

五轮专家执行比例约为70%、49%、34%、24%、17%，建议每轮2000局。重点收集连续无信号、错误长距离移动、平行交会、粒子多峰、清除失败、漏扫频道和第四问定向源背面等状态。

DAgger必须真的执行学生动作。重新生成一批专家轨迹不属于DAgger。

验收时相对于SFT应看到：学生自身轨迹清除率提高、失败清除减少、连续无信号后的恢复率提高、极端场景死循环减少。

## 5. 第三层：PPO

### 作用

SFT和DAgger负责可靠完成，PPO直接优化总虚拟时间，学习超过固定启发式专家的动作组合。

从DAgger checkpoint初始化：

\[
r_t=-\Delta T_t+500I_{success}+20\alpha_k\Delta H_t-50I_{failed}-5000I_{incomplete}.
\]

- 每增加1秒虚拟时间奖励减1；
- 清除成功奖励500；
- 清除失败惩罚50；
- 信念熵下降只在训练早期奖励，\(\alpha_k\) 逐渐退火到0；
- 全部清除额外奖励2000；
- 时间耗尽、异常退出或遗漏目标惩罚5000。

推荐参数：

```text
rollout steps：2048
batch size：256
PPO epochs：4
gamma：0.995
GAE lambda：0.95
clip：0.2
学习率：1e-4
```

Actor只能选择候选mask内的合法动作。退出由确定性覆盖门槛控制，不能让PPO自由学习exit。独立评测时关闭信息奖励，只按全部清除率和真实虚拟时间比较。

需要检查的奖励漏洞包括：反复测量刷信息奖励、重复清除刷成功奖励、只处理容易目标后退出、异常长距离移动和在同一地点反复利用固定误差。

## 6. 三层数据关系

```text
D0：专家轨迹
SFT(D0) → policy_0

D1：policy_0到达状态上的专家标签
SFT(D0 ∪ D1) → policy_1

持续聚合5轮 → policy_DAgger

policy_DAgger作为PPO初始权重
与环境交互产生rollout
根据奖励更新 → policy_PPO
```

SFT和DAgger需要逐步专家标签；PPO需要环境反馈和奖励，不需要逐步标准答案。

## 7. 最小实施顺序

1. 运行环境规则、观测可见性和几何覆盖自检；
2. 生成问题3的1000局专家数据；
3. SFT训练10—20轮；
4. 在500个未见场景跑完整轨迹；
5. 修复所有漏源、空候选和死循环；
6. 运行1轮DAgger×100局验证链路；
7. 扩大到5轮DAgger×2000局；
8. DAgger清除率稳定后启动PPO；
9. 四个随机种子在至少10000个独立场景选模；
10. 把模型复制到官方模拟器所在电脑做演练；
11. 根据官方演练差异扩大Domain Randomization并重训；
12. 冻结代码、配置和模型hash后进行正式测试。

## 8. 最终验收门槛

1. 主体专家与Actor不读取隐藏真值；
2. SFT数据无scene/trajectory泄漏；
3. DAgger采集学生真正到达的状态；
4. PPO不能绕过候选mask和退出安全层；
5. 本地至少10000个未见场景保持全部清除；
6. 时间优化不能降低全部清除率；
7. 自建模拟器结果经过官方演练校准；
8. 正式测试只执行冻结版本，不用于继续调参。
