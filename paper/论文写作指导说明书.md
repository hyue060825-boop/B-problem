## 2. 论文推荐主线

建议题目围绕“基于保守几何可行域、覆盖证书与强化学习调度的干扰源搜索和清除”。贡献应分为三层：

1. Q1 的测向交会几何与直径圆反例，为位置不确定性建模提供基础。
2. Q2 的保证接收区域与有限候选主动测量，为主动定位提供独立方法和显式算例。
3. Q3/Q4 以公开观测维护可行域，用覆盖和安全清除条件约束合法宏动作，再由 RL 决定覆盖、定位、清除的顺序。

不要将 Q2 独立模块的存在写成最终在线策略已经完整调用其 `choose_second()`。最终 controller 的 LOCALIZE 使用其自身侧翼候选生成方式。历史搜索教师、GPU 假设世界搜索、结构化特征和 belief-attention 尝试应按证据作为训练探索或附录对照，不宜全部画入最终部署算法框图。

推荐章节顺序：问题重述与符号 → 假设与信息边界 → Q1 几何 → Q2 主动测量 → Q3/Q4 完整策略 → 自建模拟器与训练 → 独立评测 → 补充分析和局限 → 附录。

## 3. 符号、目标和时间口径

| 符号 | 定义 | 注意 |
|---|---|---|
| N | 真实源数 | 只由场景生成器与评估端使用；不直接输入 actor |
| T | 从进入到合法退出的总虚拟耗时 | 包含移动、测量、换频、清除及无源确认 |
| F | 所有真实频道第一次出现正信号的最晚时间 | “发现全部”不等于已经准确定位 |
| C | 最后一次成功清除的虚拟时间 | “清除全部”的时间点 |
| H=T−C | 最后清除后的纯收尾时间 | 不包括清除前穿插的空频道搜索 |
| T_i/N_i | 第 i 局平均每源成本 | 全部完成时才与“每个源均摊成本”一致 |

主指标为先逐局计算再取平均：`mean_i(T_i/N_i)`。它不同于 `sum_i(T_i)/sum_i(N_i)`，也不同于某个源首次被发现时刻的平均值。旧文件有 `time_per_clear_s=T/ClearedCount`，若存在失败局，必须结合完成率解释，不得把失败后低耗时当作更好。

最终训练的宏动作奖励沿用 `−ΔT/100`，失败终局另罚 1000，gamma=1、GAE lambda=0.95。最终基线并没有采用历史结构化方案中的 `−ΔT/(100N)`、成功加 500、每次失败清除减 50或信息熵奖励。验证选模使用配对 T/N，这不等于训练奖励也按 N 归一化。

所有正文性能表须标明“虚拟秒”。现实推理、训练时间和通信等待另列。官方日志中的 9236.07 秒是动作虚拟成本；`real_timestamp_ms` 得到的 2.730 秒仅为进入到退出的现实时间，不含 Python 启动和模型加载。

## 4. 几何与退出条件怎样写

Q1 将测向误差扇形转为向前半平面约束，分类处理空集、无界、点、线段和有界多边形。直径端点形成的半径 D/2 圆不一定覆盖交会区域；等边三角形的显式测向构造是可复核反例。参见 [Q1 报告](../reports/问题1_结果报告.MD) 与 [算例图](../artifacts/q1/triangle/geometry.png)。

Q2 构造保证接收的内近似区域，使用有限网格和局部细化选择下一测点。报告中的后验质量估计是离散候选估计，不是连续空间全局最优或精确贝叶斯期望。参见 [Q2 报告](../reports/问题2_结果报告.MD)。

Q3 使用原点及六个外圈顶点形成的固定七点全向覆盖骨架；Q4 使用间距 995 米的三角网格生成 31 个固定认证站点。站点坐标不由 RL 任意生成；访问顺序以及与定位/清除的交错由策略决定。原控制器通常从最近三个未访问站点生成 COVER 候选。定位和清除坐标则根据公开观测动态构造。

Q3 的无信号观测可以按其全向语义更新排除区域；Q4 单次无信号不能按全向半径直接删除一整片位置域。Q4 对未知频道累计完整 31 站点负观测才能认证无源；当公开发现数达到 16，可利用题目数量上限排除其余未发现频道。退出要求全部频道已清除或已认证无源。

维护区域使用保守多边形近似，安全清除基于覆盖上界和裕量。必须区分浮点几何工程证书与精确有理数证明。31 站独立有理四叉树证明及压缩布局反例归入附录：它们不证明 31 是最少站数。`layout31_proof.json` 的有理坐标和边界裕量以文件为准，不应把独立证明描述成在线每一步都运行精确算术。

## 5. 最终神经网络架构

源码：[模型](../solution/rl/model.py)、[特征与环境](../solution/rl/environment.py)、[控制器](../solution/control/controller.py)。这三份运行代码与最终两份 checkpoint 记录的哈希匹配。

| 输入/模块 | 尺寸或做法 |
|---|---|
| 全局特征 | 10 维：位置、频道、虚拟/现实预算、公开发现及清除进度等 |
| 频道特征 | 20×9：公开状态、观测次数、方向、区域面积/半径、定位次数、覆盖进度等 |
| 候选特征 | 动态候选数×11，动作类型、位置、频道、估计成本等 |
| 编码器宽度 | 128 |
| 频道聚合 | 2 层 TransformerEncoder，4 头，前馈层 256；随后平均池化 |
| Actor | 拼接候选编码、全局编码、聚合频道编码，输出每候选 logit |
| Critic | 拼接全局与聚合频道编码，输出状态价值 |
| 动作选择 | 训练时采样；评测/部署时 greedy argmax |

最终网络没有显式将候选直接绑定到该频道 token 的交叉注意力。这是历史结构化尝试的不同设计，不能把其论文描述和本表权重混用。352386 为模型参数数目，不包含 Adam 状态。

建议框图：公开响应 → 几何/频道状态更新 → 覆盖与清除条件生成合法候选 → CandidatePolicy 排序 → 宏动作展开成 `/measure`、`/clear` → 反馈循环；全部取得条件后 `/exit`。隐藏场景只能连接到模拟器和评价模块，不能连接到策略输入。

最终 Q3 学习率 5e-6；最终 Q4 一小时学习率 1e-5。两者恢复父模型 Adam，PPO 两个 epoch，每 rank batch 64，优势按全局样本归一化，空分片零权重补齐，KL 全局共同停止。Q3 四卡每轮 128 场景；Q4 八卡每轮 256 场景。权重及优化器状态 SHA256 在各 rank 间审计一致。保存和完整验证均计入训练预算。

服务器为八张 RTX 4090。最终续训的 GPU 负责神经网络前向/反向和参数同步；研究环境、几何与 rollout worker 主要在 CPU。不能写“全部物理模拟均在 GPU”或“八卡一定带来八倍端到端加速”。GPU 搜索加速的单独实验有特定规模、回退和计时口径，其收益不能直接当作最终训练吞吐收益。

## 7. 正文主结果：只使用最终权重的直接证据

| 模型 | 独立测试 | 完成 | 平均 T（虚拟秒） | 平均 T/N（秒/源） | T 的 P95 |
|---|---|---:|---:|---:|---:|
| 最终 Q3 | q34_deadline_test3000_20260913 中 q3_candidate | 3000/3000 | 3255.759 | 255.989 | 4112.843 |
| 最终 Q4 | q4_baseline_8gpu_1h_20260913/train/final_test.json 中 student | 3000/3000 | 9685.100 | 767.252 | 12884.488 |

Q3 与其前一最佳模型在同一批样例上：平均 T 减少 15.279 秒；平均 T/N 降低约 0.453%，配对 T/N 差的 95% 区间为 [−1.466,−0.865] 秒/源。

Q4 与父基线同批比较：平均 T 从 9697.796 降到 9685.100 秒，差 −12.696 秒，95% 区间 [−31.853,+6.462] 秒。平均 T/N 从 768.160 降到 767.252 秒/源，差 −0.907，95% 区间 [−2.304,+0.490]。正确表述是“完整完成率保持 100%，均值略有改善，但尚无显著收益证据”。

这两项测试来自不同题目的不同场景集合，不能做逐场景 Q3/Q4 配对收益推断。100% 是这批有限测试的观测完成率，不等于所有可能场景的统计或形式化保证。

参考：[Q3 主评测](../runs/q34_deadline_test3000_20260913/report.md)、[Q4 主评测](../runs/q4_baseline_8gpu_1h_20260913/evaluation/report.md)。Q3 原报告中的 Q4 行是父基线成绩，不是最终 Q4。报告标题中的“六小时”是阶段描述，精确资源与用时应引用各自日志。

## 9. 重点补充分析的写法

### 9.1 Q4 父基线的无源确认开销

在原 3000 个场景中补录逐动作时间后，3000 局总时间逐例完全复现。N<16 的 2577 局：平均总耗时 10093.55 秒，平均纯收尾 H=1316.27 秒，占累计总耗时约 13.04%；H 的中位数 253.64 秒、P95 6274.08 秒，存在长尾。纯收尾时间中约 83.61% 是移动。

6000 秒后的测量约 96.27% 无信号，但约 39.58% 的局仍在此后首次发现新源。因此“后面大多没信号”不等于可以统一在 6000 秒退出。聚集场景纯收尾均值约 3207 秒，outward 场景经常晚发现；原 profile 绑定了空间分布与误差场，分层差异不能全归因于位置。

使用 [tail_analysis.png](../runs/q4_absence_tail_analysis_20260913_v2/tail_analysis.png)，图注必须带 Q4 父基线身份。H 只计最后清除之后，官方日志恰有大量确认搜索穿插于清除任务之间，所以 H=0 也不说明没有无源确认代价。

### 9.2 四组规划对照是有价值的负结果

同一父基线、3000 个新场景、同一退出证书。A 平均 9667.77 秒；仅路线 B 为 9893.00 秒；仅安全清除插入 C 为 9675.54 秒；组合 D 为 9863.41 秒。B/D 分别慢 2.33%/2.02%；C 的总时间差无显著性。

静态路线优化改变站点访问顺序，可能推迟获得有效观测、增加测量，并延后发现满 16 源后的停止覆盖。不能仅凭待访问站点路径变短就推断整局更快。C 平均全部清除时间提前 38.47 秒，而后续证书收尾仍需完成。它支持“优化应联合考虑任务与信息收益”，不是对某个全局最优调度定理的证明。

### 9.3 最短/最长样例是主动搜索结果

每题每个 N 搜索 704 个候选：8 类×64 初始分布，加四轮最快/最慢局部扰动（每端点每轮24次）。固定频道1..N、半径1000米、零误差；Q3全向，Q4定向数floor(N/2)。最终12个样例均以原实时特征复跑两次，总耗时一致。

Q3 最短总耗时为 N10…15 的 1885、1854、1823、1792、1761、1730 秒；本轮最长为 4574.99、4859.75、5532.00、5371.98、5694.42、5925.52 秒。Q4 父基线对应最短 8055.68、7934、7759、7584、7409、7234 秒，最长 16941.27、16724.01、19197.64、16725.37、18462.34、19895.55 秒。

这些不是测试均值，也不具有随机样本均值的置信区间解释；最难样例是主动挑选的。最短按整局 T 选择，表中附列 C 只是同一个代表样例的最后清除时刻，没有独立优化 C。不同 N 的极值也不必单调。

### 9.4 官方日志与部署验证

`paper/official_logs/logQ4.jsonl` 中模型哈希属于父基线。日志记录成功清除14个不同频道，没有独立给出隐藏 N；第413秒前这14个频道均已有信号，最后两次清除在6178.53和9236.07秒。按公开历史重建，频道3在1061秒已有安全清除证书，却到末尾才清除。等待间隔包含其他任务，不全是可删除成本。

## 10. 图表建议及引用方式

正文优先放：最终架构框图、Q1反例、Q2算例、最终Q3与Q4各自配对主表、两题源数分层表、训练与验证曲线。附录放：原始分布直方图、无源尾部、四组负结果、A/C最后清除折线、极端布局、证书验证、CPU/GPU与DDP检查、官方日志单例。

每张图的图注至少包含：题目、模型SHA简称、场景数量/构造方式、时间单位、是否含无源确认、是否使用旧基线。均值表需说明 T/N 的平均方式。复用历史图片时不要编辑曲线冒充新模型，应保留原图并用新图注标注身份。

训练曲线的横轴应区分 PPO iteration、Adam step、完整场景数、宏动作数和虚拟秒。不能把每个场景当作单个监督样本，也不能把累计运行轮数都算给较早保存的 best。验证集反复使用用于选模，测试集保持独立。

推荐结果叙述模板：

> 在自建相容研究分布生成的3000个独立场景上，最终Q4策略完整完成3000局，平均总虚拟耗时为9685.10秒。相对于相同架构父模型，配对均值差为−12.70秒，95%区间为[−31.85,+6.46]秒。观察到小幅均值下降，但未获得显著改善证据。本文因此不将一小时延长训练作为主要性能贡献。

## 11. 不能从现有材料推出的结论

- 自建随机分布与官方隐藏测试分布相同；官方误差场及部分数值约定在历史材料中仍有假设。
- 31个站点最少、固定候选搜索全局最优、主动找到的最坏样例是理论上界。
- Q4无信号能够直接排除完整圆盘，或大多数晚期测量无信号就能无损提前退出。
- 所有历史GPU任务都是同步DDP、整个模拟器都在GPU、算力增加必然带来同比加速。
- 阴性结果因没有NaN就说明模型效果良好；有限损失和策略性能是不同指标。
- 旧attention、structural或belief模型的指标/特征就是最终权重的架构。
- 因用户最终指定某模型，就将不显著的测试差异改写为显著进步。
