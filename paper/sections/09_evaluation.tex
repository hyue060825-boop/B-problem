\section{模型评价与推广}

\subsection{模型优点}
\begin{itemize}
  \item 将有界误差转化为显式几何集合，定位、清除和退出均有可核验的判定条件；
  \item 问题二先保证能够再次接收信号，再优化定位质量，避免把未知接收半径固定为上界；
  \item 问题三的七点骨架和问题四的三角网格均给出连续域覆盖证明，不依赖有限随机采样宣称完备性；
  \item 搜索、顺路补测和清除共享同一频道状态，可利用 \texttt{near} 和失败清除中的确定信息减少重复动作。
\end{itemize}

\subsection{模型局限与改进}
官方场景的联合生成分布、固定误差场的空间相关结构以及部分浮点量化细节尚未公开，本地模拟器只能复现已知规则，最终参数仍需通过官方演练核验。物理可行域在圆盘排除后可能非凸，保守外包过粗时会延迟清除；可通过自适应细化和精确区域运算改善。三角网格提供发现保证，但完整扫描成本较高，后续可在不破坏覆盖证书的前提下优化网格相位和访问路线。若引入学习调度，只允许其在合法候选动作间排序，并须先证明完成率不低于确定性基线。

\subsection{模型推广}
该框架适用于观测误差有界、传感范围未知且必须保证任务完成的主动搜索问题，例如灾害搜救、移动传感器布设、无人机信号源搜索和巡检路径规划。
