\section{模型假设}

结合题目公开规则，作如下建模约定：
\begin{itemize}
  \item \textbf{约定 1：}机器人位置和被接受动作的执行结果准确，移动过程不考虑额外障碍；
  \item \textbf{约定 2：}示向度误差只采用题目给出的有界条件 $[-1^\circ,1^\circ]$。同一地点的误差固定，不假设不同地点的误差独立同分布，也不通过重复测量平均消除误差；
  \item \textbf{约定 3：}干扰源在一次任务中位置、频道、有效接收半径、类型与发射方向保持不变，每个频道至多对应一个源；
  \item \textbf{约定 4：}有效接收半径始终保留为 $[1000,1500]\,\mathrm{m}$ 内的未知量，不以其上界代替真实半径；
  \item \textbf{约定 5：}只有服务器确认接受的动作才更新位置、当前测向频道和虚拟时间；网络重试复用同一请求标识；
  \item \textbf{约定 6：}理论证明使用题目给出的闭边界，程序实现另加数值保护量，并通过边界测试检查其影响。
\end{itemize}
