# Q3 3000 局独立随机测试

本目录记录使用 `runs/large_20260911/q3_ext_gpu2/best.pt` 在自建 `LOCAL-RESEARCH` 模拟器上的 3000 局测试。

每局定义：

```text
t_i = 该局 virtual_time_s / 该局成功清除的源数量
```

用户要求的总体平均为 `sum(t_i) / 3000`，结果为 **261.649950 s/source**。作为补充，按所有局总虚拟时间除以所有已清除源总数的加权结果为 **256.229140 s/source**。

- 完成率：3000 / 3000 = 100%
- 中位数：264.348186 s/source
- P05 / P95：166.060715 / 350.254047 s/source
- 最小 / 最大：67.413332 / 430.544548 s/source
- 总虚拟时间：9,999,085.947458 s
- 总清除源数：39,024
- 墙钟耗时：48.37 s（8 个 CPU 推理 worker）

`samples.json` 保存每局结果，`summary.json` 保存聚合统计，`per_source_time_distribution.png` 是每局平均每源时间直方图。样本来自四类位置分布和三类误差场的自建研究生成器，不是官方隐藏测试样例。
