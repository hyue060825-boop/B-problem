前端是无外部依赖的HTML/CSS/JavaScript，地图使用Canvas。管理服务与内核同用Python标准库，无需npm、前端构建或在线CDN。源码为 `bsim/web_dashboard.py` 和 `bsim/web/`。

## 权限与限制

管理服务只绑定127.0.0.1，API使用每次启动生成的Bearer密钥。密钥通过终端完整链接的fragment传给页面，然后从地址栏移除，保存在sessionStorage。策略只拿机器人端口和LOCAL-TEAM标识；不应获知管理密钥或管理对象。此机制不构成对同一系统用户恶意读内存/文件的OS沙箱。

网页里的“混合源展示夹具”是手工指定的确定性场景，绝不代表官方随机联合分布。固定零误差是TEST_INPUT。G01—G09的缺口及完整strict阻断保持原有状态。

页面默认只显示公开响应可推导的轨迹和计数；管理端调试的真值单独调用鉴权端点获取，不加入策略观测。尚未实现历史会话数据库，进程退出或新建会话后旧内存记录不保留，因此需要保留时应先导出。

## 启动

```bash
python3 -m bsim web --port 8765 --robot-port 20260
```

打开终端打印的完整链接即可。启动命令本身只开管理网页，按下“开始本地会话”才创建LOCAL仿真会话，倒计时结束后开放20260机器人端口。网页管理API不承诺与官方协议同形；官方兼容约束仅适用于独立机器人四接口。
