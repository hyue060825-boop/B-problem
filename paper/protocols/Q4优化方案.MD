## M1：目标函数、优势估计、选模标准对齐

### 训练目标

完成局目标是 J=E_episode[T/N]，而非 E[T]，也不是 sum(T)/sum(N)。训练侧在整局固定真实 N，对每个宏动作采用：

`r_t = -ΔT_t / (time_scale * N)`

time_scale 为固定正数，默认可取 100，写入配置与 checkpoint；γ=1 保持有限时域时间目标。ΔT 必须包括宏动作实际执行的全部移动、测量、切频、自动 near-clear 和 probe 成本，不能使用候选估价代替。

若加入势函数 shaping，给出 γ=1 下终端势为零的推导，并提供关闭开关。先不加入任意“信息增益奖励”，避免重新偏离总耗时目标。

失败惩罚与正常时间项分开：不能机械保留旧 -1000 量级后不验证，也不能把除以实际 C 的指标直接变成可被提前退出利用的奖励。依据现有虚拟时限与动作越限语义，给出尺度合理的固定惩罚或受约束目标，单独测试“早失败更快”不会通过选模。有限惩罚不等于数学上保证零失败；正式准入仍要求所有评估局完成。

真实 N 仅存于 trainer/evaluator 的私有数据，不能进入 actor、candidate generator、belief、teacher、recurrent state 或策略历史。增加泄漏回归：固定完全相同的公开历史，仅改变评估侧隐藏元数据时，动作集合和策略输入必须相同。

### PPO/DDP 审计

1. 梳理 `advantages`、GAE、reward normalization、minibatch sampler、loss reduction 和 DDP 全局归一化；防止逐 episode 标准化把 1/N 权重抵消。
2. 用解析两回合例子证明成功局 reward sum = -T/(time_scale*N)，并验证单卡与多卡产生一致的目标梯度方向。
3. 区分对每回合 trajectory gradient 求和与对所有 transition 求均值；给出所选 reduction 对 E_episode[T/N] 的关系。不要额外无依据除以 episode 长度；PPO 的近似优化性质如实说明。
4. 若重采样低 N 场景，区分压力测试分层与训练目标分布。需要时使用显式分布权重，避免改变目标后仍声称原分布完全对齐。
5. 调整 value loss 尺度、entropy 系数和 gradient clipping 时记录依据，监测 KL、clip fraction、value error 和 entropy，防止 reward 尺度变化导致优化器失衡。

### 评估与选模

统一产生以下字段：completion、N、C、total_virtual_time、time_per_source、失败原因、路径、测量、切频、failed clear、absence 覆盖耗时、决策墙钟。

- 失败局全部保留；C=0 用 null 加明确失败标志，不能静默删掉后计算“全局平均”。部分完成局 T/C 仅诊断，不能参与成功模型的效率排名。
- validation 候选只有在全部完成时才具备准入资格；按 `mean_case_time_per_source` 选 best。
- 对同场景基线计算 `Δ_i=T_new_i/N_i-T_base_i/N_i`，报告配对均值和 95% CI；使用预先固定的统计方案。最终确认不要使用逐轮挑中的最有利测试结果。

## M2：让 Q4 belief 成为可用、可信的规划输入

### 修正当前 belief 的语义

现有 `summary_at().entropy` 是收到/收不到信号的二元熵，不能改个名字就声称完整 posterior entropy 或完整 EIG。`best_localize_points()` 目前按该二元熵排序；将其作为明确标注的便宜代理保留，再实现有定义的观测分支信息量。

粒子至少包含 position/radius/kind/heading/weight。对 UNKNOWN 频道必须区分：

- 假设源存在条件下的接收概率；
- 如果维护存在概率，则连同 no-source hypothesis 和显式研究先验一起维护。

不能把 `P(reception | exists)` 当成 `P(exists)`，也不能使用真实场景 N 决定 UNKNOWN 的先验。可使用公开 10–16 上下界；逐频道独立近似未包含跨频道相关性时必须标注。

可见性和似然与 ReferenceKernel 一致：半径闭边界、directional 的闭半平面、cardinal heading、boundary_epsilon、重合 visible/invisible/blocked、near 的 5 m 门槛、direction 与 near 的区别、角度噪声/量化、同地点固定误差、failed clear 的 20 m 约束及清除后状态。不能把固定误差当成每次独立新噪声来虚构信息收益。

planning 粒子只在真实源圆域内采样，不能把 feasible region 的外包多边形当成物理源域。拒绝率、退化区域和多边形方向均需处理。

### 增量更新与 GPU 批量计算

1. 去掉仅每四次观测且 count=8 的决策级限制。默认尝试 128 粒子，提供 64/128/256 消融；每次接受的新观测增量更新，按 ESS/退化触发补样与重采样。
2. 粒子不足时报告 valid、ESS、age、degenerate 等状态并启用规划回退，不能把空 belief 编码成“确定没有源”。
3. 大量粒子似然、可见性、权重归一化、位置协方差、circular heading statistics、candidate×particle 评分用 GPU 批量实现。
4. 跨环境/频道合并请求，粒子和缓存尽量驻留 GPU；缓存键包括公开历史版本、belief 配置/数值语义和候选坐标。避免每次 legal_actions 重建 tensor 或逐点 `.cpu()` 同步。
5. 保留 CPU reference 与小批 CPU 路径；相同公开历史和 seed 下做概率/排序一致性检查，不把随机重采样差异误认为模型收益。

### 有明确含义的特征

channel token 至少包含：belief_valid、粒子数、ESS、belief_age、conditional reception probability at current position、directional_fraction、空间协方差/离散度、位置不确定性估计、heading 的 sin/cos 均值与集中度。若加存在概率，必须注明先验与近似。

candidate token 或 candidate-channel relation 至少包含：

- 目标点接收概率与 near 概率；
- receive/no-signal entropy proxy；
- 观测分支 EIG 或期望空间不确定性下降；
- probe 清除成功概率及预期失败成本；
- 确定性 certificate progress、移动/切频/测量成本。

EIG 必须写明定义，例如 `H(weights)-E_y[H(weights|y)]`。若观测结果分箱，定义 no_signal/near/direction angle bins 与噪声条件化，报告分箱误差及有限粒子近似；二元代理与完整观测分支版本做消融。不要把粒子数增加带来的 log(H) 增量误当真实不确定性变大。

COVER 对扫描频道汇总信息量与接收概率，只有独立近似成立时才能直接解释概率乘积；预计新增发现数的边缘概率求和与“至少发现一个”的概率不是同一统计量。

替换环境中 `q4_belief_reception_probability_at_selected=0.0` 的占位值，记录动作执行前真正选中候选的值；多频道 COVER 保存频道明细和汇总，不能只对最终机器人位置重新算后冒充动作前诊断。

交付：GPU/CPU belief 后端、版本化特征、缓存、退化回退、合成公开历史测试、概率校准/信息量诊断、M2 消融。

## M3：实现真正的 candidate cross-attention

不要只扩大 hidden 或将 gather+concat 政名。新增有独立 model_version 的策略结构：

1. global/channel/station/candidate 分别编码；candidate embedding 作为 Query。
2. channel Key/Value 使用 channel tokens；COVER 的目标集合为完整 scan mask，LOCALIZE/CLEAR/PROBE 为其绑定频道。
3. candidate→station attention 根据动作是否绑定 station 和公开 route 信息构造。需要全局站点上下文时单独设置合法上下文，不能把无绑定站点误当 station 0。
4. 保留 optional masked-mean scan context 作为较简单对照，真正 attention 应有随 candidate query 变化的权重。
5. 真正使用 candidate_channel_valid、candidate_station_valid；无绑定项用显式 null token 或零上下文。EXIT 及全 mask 情况不能产生 NaN。
6. 增加 station padding mask、candidate padding mask；padding 不进入 attention 或 critic pooling。channel mask 与 invalid relation 在 self-attention/cross-attention 链路中的含义分别写清。
7. critic 从公开状态表示输出 value；不要引入真实 N 等隐藏状态。
8. channel/station 索引仅用于绑定。尽量移除无物理意义的绝对 ID 数值编码，用 current-channel 指示与 route rank 表达相关关系。频道重命名、站点存储重排后，绑定与 mask 一致变换，logits 应按动作对应关系保持一致；固定可重复的平局规则。
9. 从 structural_features→model_state 白名单→collate→DDP→inference→checkpoint→export/run_policy 全链路传递新增字段，防止特征计算出来后再次被白名单丢掉。
10. 不强加载旧权重或 Adam 状态到新结构。若迁移兼容层，输出精确迁移清单，重置不兼容状态；冻结基线继续使用原模型定义。

测试必须包含：无 station 的 LOCALIZE 不读取绑定 station 0；EXIT 全 mask；混合 station 数量的 batch；COVER 非首个被扫描频道的信息变化能改变其目标集合上下文；padding 扰动不影响有效输出；候选顺序等变；正确频道重命名的等价性；attention 对查询和相关 token 有有效梯度。若 channel encoder 允许全局上下文，不能要求所有未扫描频道对最终分数绝对零影响，应单独验证目标 mask 聚合本身。

交付：真实 attention 模型、简单 masked-mean 对照、完整 schema 升级、回归测试、M3 消融。

## M4：belief-aware LOCALIZE/COVER 与 probe 决策

### LOCALIZE

保留旧 SVD flank 和可靠回退点，加入根据公开 region/belief 生成的多方向、多尺度候选点池，在 GPU 对全部候选批量评分。

候选来源至少覆盖：高接收概率、高二元信息熵、高观测 EIG/空间收缩、低绕路成本。调用升级后的 best_localize_points，或将其替换为同职责接口，并证明实际 legal_actions 已使用。

候选上限、每频道 quota、空间去重、相同频道精确重复测量过滤必须配置化；保留多样性，避免 top-k 全是几乎相同的点。不能无限增加候选使在线决策超时。

### COVER

从剩余 certificate stations 中并列提供 route.next、最近站、预计发现价值最高站、已知源定位价值最高站、信息/秒高价值站。可以扩展额外测量点，但额外点的测量不能冒充 certificate station。

替换 known[:3] 的频道顺序选择，按该站处预期信息收益、正测概率、附加测量/切频成本排序；提供 CERT_REQUIRED 和 CERT_PLUS_HIGH_VALUE_KNOWN 等受控集合。需要部分 required scan 时，保留每频道独立进度、补测动作和最终完成路径，不把“访问过站”当作“所有频道都测过”。

成本按真实动作执行计划估计：move/5 + 5×measure_count + actual_switch_count，加上模型明确计入的自动 clear 期望项；不能把 6×channels 一律当精确成本。记录估价与真实成本差异，保证候选、特征、实际执行的坐标/频道顺序一致。

### PROBE/CLEAR

概率仅影响尝试 probe 的决策，不产生 certified CLEAR。仍保留有限完整 probe cover 和退出/进度保证；不能因低概率永远禁止必要 probe。设置可解释的饥饿/停滞回退，避免不断贪信息量却不完成覆盖。

BC/DAgger 的 teacher 使用更新后的公开信息打分或公开历史条件化的反事实短搜索。不能继续用旧固定偏置给所有新候选贴差标签；也不能用真实当前场景的隐藏源挑最优动作。

交付：候选生成/打分/teacher 更新、重复和饥饿回退测试、动作前后计划一致性、no-signal→belief 更新→候选变化→策略变化的端到端证据、M4 消融。

## C0：建立准确的数学规格和工程规格

### 物理域

源域 D={p∈R²: ||p||≤1800}，最坏接收半径 R=1000。定向覆盖角为含边界的 180°。对于非重合 p≠s，理想规则是：

`visible(p,u,s) ⇔ ||s-p||≤R 且 u·(s-p)≥0，||u||=1`。

ReferenceKernel 对 p=s 有单独的 directional_overlap 分支，研究默认 invisible。因此必须以排除零向量后的集合证明：

`A(p)={s∈S: 0<||s-p||≤R}`

`∀p∈D，p∈conv(A(p))`。

对非空有限集合，这与所有 heading 至少有一个站可见等价，写出凸组合与严格分离两方向证明。空集合、单站、重复站、共线站与闭半平面边界都单独定义。

机器人允许走出 1800 m 源圆域。当前规则记录坐标分量绝对值≤2,000,000 m；以 protocol 实际限制核验，不要误将测站投影进源圆。如果全部有限测站都被限制在同一个严格凸圆盘内，要覆盖其完整圆周的向外 heading 会发生几何障碍；不能加上这个错误约束后盲目搜索。可以为效率使用更小的测站搜索框，但必须注明那只是搜索子域，不是原题限制或最优性结论。

### 数据结构与返回状态

创建独立的版本化 layout/certificate schema，至少包含：

- 站点坐标、稳定 station_id、坐标单位与精确表示；
- 源域、R、保守证明半径 R_cert、overlap、边界语义；
- 搜索配置/seed/预算/GPU/代码哈希；
- 证明单元、witness station IDs、空间细分树或精确网格拓扑；
- 重合点 guards、距离裕量、凸包内部裕量；
- 搜索诊断、反例、未决单元、精确验证结果与证书哈希。

状态分开：CANDIDATE、FALSIFIED、NO_COUNTEREXAMPLE_FOUND、PROVED_MATH、VERIFIED_RUNTIME、UNKNOWN、INVALID_ARTIFACT。搜索未发现反例不是 PROVED；证明器资源耗尽不是 FALSIFIED。

### 先验证基础工具

为新 verifier 构造小型已知正例与反例，并尝试对原 31 站构造导出独立证书。当前 grid 含 sqrt(3) 浮点坐标，可使用有理化后重新证明的参考布局，或明确表示原布局的精确代数坐标；有理化改变了布局，必须标明并重新核验，不能默认继承原证明。

## C1：GPU 布局搜索，两条路线依次推进

实现 `scripts/search_q4_certificate_gpu.py`，支持 CUDA 设备、K、种群数、多起点、随机 seed、采样规模、chunk size、显存预算、时间预算、恢复 checkpoint 和输出目录。

优先搜索 K=30、29、28，再向下递减。可并行探索更小 K，但不跳过近邻可行性探索，也不把找不到布局写成不存在布局。初始布局至少包括：原网格删点+局部重排、非均匀三角网格、多环/中心混合布局、随机多起点。

### 路线 A：可复用的短边三角覆盖构造

寻找站点三角形组成的无洞覆盖区域，使整个 D 被覆盖、每个使用三角形最大边长≤R_cert<1000，并具有重合点额外 guards。

GPU 优化坐标、边长惩罚、采样覆盖与路线成本；CPU 可维护三角拓扑、局部翻边和准确边界。不能把不连续拓扑优化伪装成单纯可微问题。

证明仍须验证整个圆域覆盖，不能只验证三角形边长或几个圆周采样点。成功后保存独立 proof artifact。

### 路线 B：直接优化局部凸包条件

对固定 p，GPU 计算所有有效非零向量 v_i=s_i-p，过滤距离>R_search 的站，按极角排序并计算含首尾环绕的最大角间隙 Δmax。

在有效向量集合非空且正确处理退化的前提下：

`p∈conv(A(p)) ⇔ Δmax≤π`。

0 个有效站必须失败；1 个有效站必须失败；2 个站只在严格相反方向的闭边界情形可能通过。排除全部重合站，重复极角不能引入虚假覆盖。浮点 atan2 排序和 π 比较只作搜索/诊断；精确复核改用方向叉积、凸包及精确谓词。

主要搜索与攻击路径消除 heading 枚举维度，使用 O(batch_positions × K) 的分块距离/角度数据。不要申请 positions×headings×stations 的巨大四维张量。

为坐标优化可使用分块的可微 surrogate：

`M(p,u)=max_i min(R_search-||s_i-p||, λ u·(s_i-p))`

用 smooth min/max、Adam、进化或多起点随机搜索等方法，但须注明这是代理。邻站集合随位置变化有不连续性；只对当前固定邻站集求梯度不能替代跨距离边界攻击。用准确非平滑诊断和 CEGIS 反例集约束结果。

默认可从 R_search=995 m 或 990 m 开始，R_cert 是最终证明单独选定的有理数且小于1000；若试验使用不同半径，写入证书。距离裕量和方向/凸包内部裕量分别优化，不能将角度量和米直接无归一化相加。

### 多目标与 GPU 调度

可行性是硬约束；在其基础上维护 K、开放路线长度、精确可证裕量、实际预估测量/切频成本的 Pareto 集。不要用较短路径抵消几何漏洞。

不同 GPU 独立搜索不同 K/初始化，定期交换最优布局与反例池，不需要训练用 DDP。GPU 批量评估种群、p×station 距离、角度、损失和可批处理路径近似；小规模精确组合/拓扑留 CPU。

来源 p 采样覆盖均匀面积、边界带、精确圆周、测站周围、R_search/R_cert/R 圆边界两侧、圆交点、站点连线与近共线构型。Sobol 到圆域的映射使用正确半径分布，不把均匀 r 当均匀面积。

## C2：GPU 反例挖掘与闭环优化

实现 `scripts/falsify_q4_certificate_gpu.py` 与可复用反例池：

1. 对每个候选分块评估百万量级位置；优选布局在预算允许下做累计千万量级压力搜索，记录精确样本数和所有 seed。样本多寡不改变它仍是经验检测的性质。
2. 对危险区域自适应加密：||p||≈1800、||s-p||≈1000/证明半径、max-angle-gap≈π、两圆/三圆交界、station 本身和其微小邻域。
3. 在最坏位置附近做投影局部优化或多尺度无梯度搜索，跨邻站距离边界搜索。heading 可从分离凸包或角间隙构造，不需全角度穷举。
4. 输出反例至少包含精确/高精度位置描述、heading 或分离方向、哪些站超距、哪些站处于背面、每站 margin、是否重合、CPU ReferenceKernel 回放结果。
5. 将浮点疑似反例分为 confirmed 和 unresolved。只有经过可靠复核的反例才能判 FALSIFIED；边界不确定不能被容差抹掉。
6. 把 confirmed 反例和证明器的未决区域加入下一轮优化数据；保留旧反例回归集，形成 search→attack→repair→attack 的 CEGIS 闭环。
7. 最优坐标 snap 到整数、0.5 m 或 0.1 m 等有理格点；逐级尝试，snap 后重新搜索/攻击/证明。证明只针对最终冻结坐标，不能继承 snap 前通过状态。

对排除零向量后的方向集合构造严格分离 heading 时，如果只得到接近边界且无法确认全部不可见，则保留疑似状态。反例中的距离和方向谓词要与 radius=1000、overlap=invisible 的实际目标语义核验。

## C3：主攻 GPU 构造 witness + CPU 精确复核的连续域证明

这是本任务重点，必须真正实现，不能停在随机采样验证。

### 证明引理

设 C 是有理顶点的凸验证单元，例如三角形或矩形。选择若干站 W_C，优先尝试三站 witness triple。对 C 每个顶点 v 精确验证：

1. `v∈conv(W_C)`；
2. 对每个 s∈W_C，`||v-s||²≤R_cert²`，其中 R_cert<1000。

由凸性，得到整个 C⊆conv(W_C)，且 C⊆∩_{s∈W_C}B(s,R_cert)。所以对 C 内所有非重合源位置、所有 heading 至少有一个有效站可见。源与站重合另按 C4 处理。

三站的特殊形式是：

`C⊆conv(s_a,s_b,s_c)∩B(s_a,R_cert)∩B(s_b,R_cert)∩B(s_c,R_cert)`。

该证明只要求站点到验证单元全部顶点的距离有界，不要求 witness 三角形的三条边都<1000，因此严格不同于只搜索短边三角剖分。必须利用这个更宽松的构造条件。

### 为什么不能只反复细分然后宣称一定成功

逐点 Carathéodory 定理给出“每点至多三个站可作见证”，不保证一个预设小单元所有点共用同一组三站，也不保证某个浮点可行布局存在当前证书模板的有限细分。

在 witness 切换线、共线/对径构型、圆边界等位置，固定三站模板可能反复失败。实现多种救援方式：

- 自适应细分与与站点连线对齐的有理三角单元；
- 允许 witness 是四个或更多站组成的精确凸包，仍按同一凸性引理逐顶点验证；
- 将未决区域反馈给布局搜索，让新布局具有严格正裕量；
- 预算耗尽返回 UNKNOWN，保存全部未决单元，绝不当作安全或几何不可能。

优先实现通用 witness convex hull，避免把“必须三站”误当成原问题要求。

### 全域覆盖：推荐可独立复核的有理四叉树

从根正方形 Q=[-1800,1800]² 开始。所有细分坐标使用有理二分点。每个叶子只能是以下一种：

- OUTSIDE：精确证明该闭矩形到原点最短距离平方>1800²；严格大于才可忽略。等于的切触点属于源圆域，不能删掉。
- WITNESS：整个闭单元满足上面的 witness 引理，包括单元落在源圆域以外的部分；这是保守充分条件。
- UNKNOWN：仍与 D 相交且无已验证 witness。

GPU 对活跃叶子做近邻站筛选、顶点距离测试、三角形 orientation/barycentric 候选测试、witness 打分和 top-k，CPU 对候选 witness 用精确数复核。无 witness 的相关单元继续四分；需要三角形时明确记录对角线和子单元。

CPU verifier 从根重新生成细分树，检查每个父节点是否精确分成全部子节点、深度/坐标一致、无缺失叶子、无非法覆盖标记。根覆盖 D、OUTSIDE 真正不交 D、其余叶子均有证明，且不存在 UNKNOWN，才可推出全域覆盖。边和顶点采用闭集合，不能遗漏测度零集合。

这个方案无需将真实圆周替换成内接多边形，也无需相信浮点 Shapely union。某些近边界单元因要求连同圆外部分一起可证而难以终止，是保守模板局限，不能偷偷删掉圆外/边界部分。可以继续优化布局、细分，或切换到明确证明覆盖 D 的有理外包多边形与精确平面网格。

若使用外包多边形路线，独立证明 D 包含于外包多边形，并精确验证其三角剖分完整、无洞、不自交。只检查各小三角形自身合法或面积之和相等不足以证明无洞覆盖。

### GPU witness 配对的工程要求

对每个 cell，先批量计算所有 station 到全部 cell 顶点的最大平方距离，筛出能覆盖整个 cell 的站。只在该近邻集合枚举三站/小凸包，避免直接构造 cells×C(K,3)×vertices 的全量张量。

按 cell block、candidate witness block 分块，保留少量可能 witness IDs 和 margin 下界候选；尽量让叶子、站点及候选缓存驻留 GPU。优先验证最有裕量的 witness。station 数通常≤31，但 cell 可能很大，必须输出显存与配对吞吐。

GPU 浮点筛选可误杀而导致 UNKNOWN，但不得放行未精确复核的单元。最终 verifier 自己重新检查全部提交的 witness，不读取搜索器给出的“通过布尔值”作为证据。

### CPU 精确谓词

- 最终站点和 cell 坐标使用整数/分母/十进制字符串，解析为 Fraction 或等价精确有理数；不要先转 float 再 Fraction。
- point-in-triangle 使用精确有符号叉积，验证三角形非退化；更大 witness 使用精确 convex hull 与闭半平面检测。
- 平方距离比较采用整数交叉相乘或有理数运算，避免不必要 sqrt。
- 对共线、重复点和空 hull 明确拒绝或使用正确退化判定，不能除以零或默认通过。
- 单纯 Decimal 高精度并不等于 exact。必须处理无界误差、符号不确定和精度不足；如果某部分用区间算术，使用有保证的外向舍入。
- 规模较大时可用多核 CPU 并行复核各叶子，但仍需主验证器验证全局结构和完整性。

实现独立的 `scripts/verify_q4_certificate_exact.py`，即使没有 CUDA、没有训练 checkpoint、没有随机生成器也能验证 proof artifact。

## C4：补全 overlap、边界与运行数值闭环

### 重合点

对每个落在闭源圆域内的最终 station 位置 p，删除所有与 p 重合的站点，不仅删除一个 station ID，然后精确验证：

`p∈conv({s∈S: s≠p 且 ||s-p||≤R_cert})`。

以有限 guard 列表纳入 proof artifact，由 verifier 自己枚举所有域内 station 位置并确认无遗漏。域外 station 不会与域内源完全重合；圆周上的 station 仍须处理。

该有限点检查只解决严格的 p=s 分支；它不自动解决邻域浮点误差或任意朝向边界，二者分开验证。

### 理想数学证明与运行实现

R_cert<1000 给距离裕量，不自动给方向裕量。凸包闭边界可能只保证某站点积恰好为0，而运行代码包含 float 坐标差和点积。

优先让证书具有严格内部裕量：对每个 cell 证明其与 witness hull 每条边的内侧距离至少 η>0。若 hull 半平面是 a·x≤b，则对每个 cell 顶点 v 检查 slack=b-a·v≥0 且 `slack²≥η²||a||²`，可用有理数精确验证。于是 C 加半径 η 的圆盘仍在 witness hull 中，得到所有单位方向至少有一个正点积≥η。重合 guard 也尽量提供严格内部裕量。

将坐标序列化、float 解析、站点匹配容差、减法/乘加舍入以及 heading 向量范数的有效误差界与上述裕量联系起来。注意 ReferenceKernel 同一 heading 的向量对各站一致，完整 convex-hull 条件对任意非零方向都成立，但每次浮点点积仍可能引入误差；不能用“heading 都采样过”替代误差分析。

若不能给出某种边界实现的覆盖保证，则单独报告 PROVED_MATH 与 runtime audit 的范围，不能标成无条件 VERIFIED_RUNTIME。与现有 G06 未决事项保持一致，不宣称解决了官方未明确的任意浮点语义。

proof artifact 必须针对最终实际请求坐标。核对 JSON 数值往返、Decimal(str(...)) 距离输入和 Controller 当前“距离站点≤1e-6 就计入覆盖”的逻辑：应收紧为受证明的坐标匹配，或把该误差显式纳入距离/方向裕量。不能证明站点 s，却在未经约束的 s+δ 测量后记作 s 的证据。

### 证明器攻击测试

至少加入以下 mutation/negative tests，错误证书必须被拒绝：

- 删掉一个相交叶子或子树；把相交叶子标成 OUTSIDE；圆周切触误删；
- witness ID 错误、重复三站、共线三站、顶点恰在边上的正确正例；
- 坐标被改、距离刚超 R_cert、单位或分母错误、有限浮点溢出；
- p=s 的自证漏洞、多个重复 station、遗漏域内 overlap guard；
- 只靠半径外站或仅一个非零站的假证书；
- snap 前后 layout/hash 混用；UNKNOWN 冒充 WITNESS；
- 伪造 claimed margin、GPU PASS 标志或 proof summary，verifier 仍独立复算。

同时保留精确边界正确正例，避免 verifier 为了“安全”把所有边界都错误判成反例。

## C5：更强路线，只在主线遇到瓶颈时推进

若 witness 单元方案长期产生 UNKNOWN，先诊断是布局真实失效、零裕量，还是模板不能表达。可以研究：

1. 以 station 距离圆 arrangement 划分源域，使有效站集合在开放面内固定，再验证每个面、圆弧、交点及源域边界是否位于对应凸包；需要严格代数/区间计算和全部低维边界处理。不能只检查 arrangement 顶点。
2. 直接对 (x,y,heading) 反例存在性构造可靠区间分支定界，证明全部域不存在漏检；点积/距离不等式、周期 heading、重合例外和 outward rounding 全部明确。

这些是备选严格方法，不是要求全部重写。优先把可运行的 witness 证书闭环完成。对历史多次 no_signal 的在线累计 certificate，另设研究开关；没有独立连续域证明时，不因 posterior 空或粒子为空而提前认证 absence。

## C6：接回 controller，并验证实际耗时

1. 启动时加载固定布局和其精确验证结果，核验 layout/proof/schema/version/hash 对应。CPU 验证可在可信发布步骤完整执行并缓存结果；运行端必须确保实际内容匹配，不能只相信 JSON 内的 certified=true。
