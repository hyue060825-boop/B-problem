# 仓库共享技能

- [academic-plotting](academic-plotting/SKILL.md)：实验图表、流程图和示意图，默认面向中文论文，保留数据来源与绘图代码。
- [awesome-ai-research-writing](awesome-ai-research-writing/SKILL.md)：中文润色、逻辑检查、图表标题和实验分析等局部写作。

在 `B-problem` 仓库内使用 Codex，可按任务自动选用，也可显式使用 `$academic-plotting` 或 `$awesome-ai-research-writing`。

两份技能来自现有本机技能库，增加了本队中文写作与交付约定；原参考资料及写作提示词库保留，仅按需阅读。建模和实验侧通过 `handoff/` 交付材料，`paper/` 由论文手维护。
