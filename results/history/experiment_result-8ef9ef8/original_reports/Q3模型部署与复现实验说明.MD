# Q3 模型部署与复现实验说明

本次模型结构、特征与合法候选均保持旧 Q3 权重兼容；训练/搜索/部署使用 `environment.py::features()`。部署仅执行固定模型推理，不加载离线搜索场景或标签。实际官方模拟器尚未运行。

## 已验证的本地 HTTP 闭环

`scripts/check_q3_local_http.py` 创建自建 LOCAL-RESEARCH Session，在 `127.0.0.1` 的系统分配空闲端口启动服务器，再用真实 `scripts/run_policy.py` 子进程执行 `/enter → measure/clear → exit`。不会连接已有 2026 服务。

实际命令：

```bash
CUDA_VISIBLE_DEVICES='' scripts/run_python.sh scripts/check_q3_local_http.py \
  --checkpoint runs/q3_joint_20260912/smoke_v2/sft_smoke.pt \
  --output runs/q3_joint_20260912/http_smoke
```

结果 PASS：10 个源全部清除并退出，141 条请求；剩余现实时间从 1199.972 秒递减到 1199.645 秒。[原始结果](../runs/q3_joint_20260912/http_smoke/summary.json)。最终推荐模型将另行执行同样的本地验证。

## 标注与四卡训练

```bash
CUDA_VISIBLE_DEVICES='' scripts/run_python.sh scripts/generate_q3_labels.py \
  --config configs/q3_joint_4gpu.json --checkpoint runs/q3_joint_20260912/baseline.pt --round 1

CUDA_VISIBLE_DEVICES=0,1,2,3 scripts/run_torchrun.sh --standalone --nnodes=1 --nproc-per-node=4 \
  scripts/train_q3_joint.py --config configs/q3_joint_4gpu.json --stage sft_round1 \
  --resume runs/q3_joint_20260912/baseline.pt --data runs/q3_joint_20260912/labels_round1/data.pt
```

第二轮以第一轮实际学生 checkpoint 采集新的 `labels_round2`，训练时同时传入两轮 `--data`。首次 baseline 初始化重置 Adam；后续阶段从同一 run_id 的统一 checkpoint 恢复 Adam 和各 rank RNG。训练目录保存阶段快照、latest、满足完成率/耗时置信度/推理开销门槛时的 best。

恢复时保持配置和阶段名，将 `--resume` 指向该作业的 latest，继续未完成的 epoch/PPO 轮；已完成实验若要重跑，应使用新输出目录和新 run_id，不能覆盖现有证据。标注脚本只重做没有原子保存完成的场景；checkpoint/配置/源码不匹配时拒绝混用部分数据。
