# 兼容范围和本地约定

这是按官方公开材料实现的LOCAL环境，不是官方二进制模拟器。Python 3.9及以上可运行，无第三方运行依赖。默认 `strict_official` 启动失败，退出码2并显示G01—G09；`fixture_conformance`必须显式提供夹具；`compatible_research`当前禁用。

## 分层

| 模块 | 职责 | 可以访问真值 |
| --- | --- | --- |
| `scenarios.py` | 场景格式、公开约束、生成器接口 | 仅管理端 |
| `noise.py` | 固定误差场接口、显式测试数值配置 | 仅内核 |
| `reference.py` | 纯物理状态转移，高精度距离与整数微秒 | 是，不回传 |
| `fast.py` | CPU距离快速筛选，边界回退参考计算 | 是，不回传 |
| `session.py`、`clocks.py` | 会话、锁、幂等、事务、时限 | 是，不回传 |
| `protocol.py`、`http_server.py` | 原始JSON校验、四接口和回环服务 | 不额外暴露 |
| `client.py`、`strategy.py` | 仅请求/响应历史及已知有效时钟 | 否 |
| `env.py` | 管理端多个独立会话批量执行，输出公开响应 | 内部可见，输出不可见 |
| `evaluation.py` | 管理端评分、重放、差异和可观测不变量核对 | 评分可见；轨迹核对不需要 |

策略替换只实现 `Policy.choose(public_history)`，返回四种动作之一。确定性算法、搜索规划器、神经网络均使用这一契约，不需要修改场景与规则。没有实现最终求解策略；`smoke-client`仅重放附件计时动作，不具有搜索能力。

HTTP适配器和进程内批量接口共用同一会话事务。管理端负责创建/reset会话、注入时间及读取评价，官方HTTP没有reset、truth、score、seed或第五个接口。`BatchEnv`只返回status、公开response和连接断开事实，不把奖励、总源数、类型等加入actor输入。

Python同一进程中的对象私有命名不是安全隔离。部署策略应在独立进程中仅接收HTTP客户端；不可将Session/Kernel/BatchEnv管理对象或夹具文件路径传入策略。当前没有OS权限沙箱，同一用户恶意读取管理端文件的防护未实现；测试验证的是数据流/字段隔离及独立进程HTTP路径，不声称隔离恶意本机代码。

## 明确的夹具约定

- 常值零误差和一个源仅是TEST输入，不代表官方误差或源数分布。正式约束校验独立保留10—16源及问题3/4类型约束。
- 坐标表误差不使用首次访问缓存随机数，没有为未知位置默认补随机值。未定义位置抛出Blocked，HTTP返回公共500，原因只在管理端`last_error`。
- 距离参考路径使用Decimal(str(坐标))、60位工作精度；方向计算使用float64 atan2/sin/cos，四个轴向单位向量精确指定。边界epsilon必须由夹具显式提供，默认夹具为0。任意旋转临界边界的官方一致性仍属G06。
- 角度：加误差、归一化、按指定模式保留两位、再次归一化。时间：每个移动段先舍入到微秒，再加整数动作耗时。二者均为TEST约定。
- 同ID内容相等按**路径和原始JSON字节**判断。相同数值但不同空白/键序也可能409；官方是否归一化等价JSON尚未公开。客户端保存并复用原始字节，不依赖这个歧义。
- 同ID执行中请求等待并返回原响应；不同动作计算或响应发送中返回409。同ID合并方式只是LOCAL约定。状态拒绝不占ID为LOCAL约定；结构/未知字段/身份不匹配不占ID有官方依据。
- 未配置官方未知容量或流量阈值。`cache_capacity`仅管理端TEST故障注入；无速率上限。不适合长时间承受恶意无界请求。
- HTTP只绑定127.0.0.1。服务在5秒倒计时之后绑定端口，结束后关闭。测试辅助`LocalServer`可保持端口绑定但关闭不可用连接；生产命令`serve`关闭监听端口。
- 请求完整读取、校验并登记后计算动作。此前到截止的请求关闭连接；已经登记的动作允许完成，虚拟时间可超过360000秒，随后结束。所有物理更新一次性提交。
- 底层HTTP以Content-Length定界；缺失/重复长度、Transfer-Encoding返回400；未完整请求5秒超时关闭连接。这些传输保护参数是LOCAL约定，G07未决。HTTP畸形请求行/头的状态由标准库解析器决定，未声称与官方逐字一致。
- HEAD按HTTP语义不发实体body；其他可形成错误响应的常规方法均返回JSON。HEAD的官方特殊行为未实测。
- 客户端仅网络失败自动原字节重试；重试耗尽保留pending动作，新动作被禁止，必须显式retry_pending。HTTP业务拒绝正常返回，由算法决定处理。结束后不尝试exit查询原因。

## 内核对比的解释

参考与快速内核的物理转移分别实现；快速内核仅加速远离距离阈值的比较，距离临界点回退参考。角度、误差和移动微秒策略共享，逐步一致不能作为这些未知官方机制的证据。批量为CPU独立会话批处理，不是CUDA张量内核；当前没有GPU后端、训练器、信念状态更新或几何策略库。

`audit-trace`用于无官方隐藏真值的请求/响应轨迹，仅检查字段、重复ID、时钟与由公开动作可算的移动/检测/清除代价。微秒差采用2微秒容差，不能确定官方舍入算法，也不能验证隐藏场景相等或固定误差场分布。`compare-traces`适用于已知同一确定性夹具，两条轨迹含请求ID时也必须一致。
